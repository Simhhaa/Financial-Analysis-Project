Financial Statement Analysis – Workbook README

File: Financial_Statement_Analysis.xlsx
Period covered: Apr-2025 to Jul-2025 (4 months), forecast to Nov-2026
Currency: ₹ (INR)
Market inputs: Price per share ₹145, 7,000 equity shares

Purpose

Monthly financial-statement analysis of a company: data cleaning, common-size analysis, ratio analysis, dashboard, forecast and written insights.

Sheet guide
#	Sheet	What it contains
1	Raw Data	Source data: P&L, Balance Sheet, Cash Flow (B3:F43). All numbers are stored as text. Market price and share count at C42:C43.
2	Cleaned Data	Same three statements, converted to numbers with VALUE(). Subtotals (Total Income, Total Expenses, PBT, PAT) are recalculated by formula.
3	Analysis	Common-size statements: P&L as % of Total Income, Balance Sheet as % of Total Assets, Expense mix (% of Total Expenses), Income mix. Includes 5 insight text boxes.
4	Ratios	26 ratios by month, grouped as Profitability, Liquidity, Efficiency, Leverage, Cash Flow, Growth & Valuation.
5	Dashboard	50 charts (bar, line, area, pie, doughnut) covering income, expenses, profitability, liquidity, leverage, cash flow, growth and valuation, plus a KPI section.
6	Forecast	Total Income / Total Expenses projected Aug-2025 to Nov-2026, and a What-If data table of PAT vs Material cost %. 3 charts.
7	Data Analysis	Descriptive, Diagnostic and Predictive commentary, with 7 charts.
8	Executive Summary	Summary and recommendations (text only).
Flow

Raw Data → Cleaned Data → Analysis / Ratios → Dashboard / Forecast → Data Analysis / Executive Summary

Other numbers: average MoM growth is 6.41% for Total Income and 7.98% for Total Expenses. Book value per share is ₹87.79 and Price-to-Book is 1.65 (Jul). Closing cash is ₹306,000 (Jul).

Forecast method
Forecast months grow at the average MoM rates: Income ×106.41%, Expenses ×107.98%.
What-If table: PAT in Jul-2025 for different Material cost % values. Each 1% change in Material cost % moves PAT by about ₹5,300, which is 12.3% of ₹43,000. Tax is held constant at ₹15,000.
How to use
Update inputs only in Raw Data. Everything else is formula-driven.
Open in Microsoft Excel. The Forecast data tables and some Dashboard charts need Excel to recalculate or display correctly.
